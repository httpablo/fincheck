# Bem-vindo à Documentação do Fincheck

O Fincheck é uma aplicação completa para gerenciamento de finanças pessoais, permitindo que os usuários monitorem suas contas bancárias, investimentos e transações de forma simples e intuitiva.

Esta documentação fornece todas as informações necessárias para entender, configurar, desenvolver e implantar o projeto Fincheck.

## Visão Geral do Projeto

O projeto é dividido em duas partes principais:

-   **API (Backend):** Desenvolvida com **Nest.js** e **TypeScript**, utilizando **Prisma** como ORM para interação com o banco de dados **PostgreSQL**. A API é responsável por toda a lógica de negócios, autenticação e gerenciamento de dados.
-   **Web (Frontend):** Desenvolvido com **React** e **TypeScript**, utilizando **Vite** como ferramenta de build. O frontend consome a API para fornecer uma interface de usuário rica e interativa.
